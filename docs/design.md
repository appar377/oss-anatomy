# 設計の基準

- Library参照: `libfile_c2c7c8e47c7c81919e7d635338841594`（読書の3画面）、`libfile_273ab9e8ca10819183b88115381c0f06`（図書館の2画面）。いずれも1536×1024のモック合成画像。正式に取得して実画像を確認。
- ロゴ参照: `libfile_bd8102fbf2ac81918434981e7ce64aa1` のA「レイヤーの断面」。濃紺のコード面、青い背面2層、少量のコーラルをSVGに落とした。
- 参照のモバイル構造を維持し、PCは図書館2列、読書の目次・本文・補助欄へ展開。生成画像の文字は転用せず、本文をDOMへ実装。
- 白・淡青・紺、青の案内、少量のコーラルの主要操作。RONLENSのプリズムやマインドマップは使わない。
- 書体はsystem fontのためロゴの字形は参照と異なる。合成モックからCSS viewportは断定せず、厳密ピクセル一致を主張しない。
- 本文はサーバーで静的HTML化し、図の選択・検索・しおり・読了・メモだけをクライアント操作にする。
- 読書の移動は履歴依存だけにせず、全体像・章一覧・前後の章を明示する。
